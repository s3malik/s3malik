# Logo sources

The logos identify current and former employers and remain the property of their owners.

- `snyk.svg`: Wikimedia Commons, "Snyk Logo.svg" (listed there as public domain, text logo). `snyk-dark.svg` is the same file with a white fill.
- `eth-zurich.svg`: Wikimedia Commons, "ETH Zürich Logo black.svg" (listed there as public domain, text logo). `eth-zurich-dark.svg` is the same file with a white fill.
- `inficon.png`: Wikimedia Commons, "INFICON-Corporate-Logo-2-Color.png", CC BY-SA 2.0, uploaded by INFICON. `inficon-dark.png` has the black lettering turned white.
- `weizenbaum-institut.svg`: logo file from weizenbaum-institut.de. `weizenbaum-institut-dark.svg` is the same file with white lettering, the gold stripes unchanged.
- `code-university.svg` and `code-university-dark.svg`: logo files from code.berlin (the site offers a dark-lettered and a white-lettered version; they are used unchanged).
